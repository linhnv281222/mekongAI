# B. Phân loại và Định dạng Output (BẮT BUỘC)

---

## 1. Dạng Tấm / Khối / Bậc / 3D

### Định dạng

```text
L x W x H
```

### Trong đó

- `L`: Chiều dài lớn nhất (trục X)
- `W`: Chiều rộng lớn nhất (trục Y)
- `H`: Chiều cao lớn nhất (trục Z)

### Ví dụ

```text
120 x 80 x 25
110 x 65 x 40
```

---

## 2. Dạng Tròn xoay / Ống / Bạc

### Định dạng

```text
Ømax x Lmax
```

### Trong đó

- `Ømax`: Đường kính ngoài lớn nhất
- `Lmax`: Chiều dài tổng thể lớn nhất

### Ví dụ

```text
Ø50 x 120
```
