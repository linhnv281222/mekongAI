## IMPORTANT — REPLY / THREAD DETECTION

An email may be the ORIGINAL message OR a REPLY in an existing thread.

**Signs this is a REPLY:**
- Subject starts with "Re:", "RE:", "Trả lời:", "答复:"
- Body contains quoted content from a previous email (lines starting with ">"), or "On ... wrote:" blocks
- Body contains only an acknowledgment: "了解", "承知しました", "Thank you", "Cảm ơn", "OK", "Received", "收到"

**RULES for REPLY:**
- Classify based on the NEW content written by the customer, NOT the quoted/previous content.
- If new content is only acknowledgment with no new request → classify as "hoi_tham" (NOT rfq).
- If new content has a new request, change, or follow-up question → classify by that content.
- When in doubt, prefer "hoi_tham" over "rfq" to avoid over-classification.
